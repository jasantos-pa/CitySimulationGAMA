# CitySimulator

Documentacion tecnica del simulador de movilidad urbana basado en agentes.

Esta web recoge las secciones principales del proyecto y organiza el contenido
en un unico arbol de navegacion, integrando tanto las paginas como sus
subsecciones.

## Contenido

- [Objetivo](objetivo.md)
- [Mapeo del entorno](mapeo.md)
- [Estadisticas](estadisticas.md)
- [Poblacion](poblacion.md)
- [Movimientos](movimientos.md)
- [Visualizacion](visualizacion.md)

## Navegacion

La estructura del sitio se define en `mkdocs.yml`. En esta version, el orden de
las secciones es:

1. Inicio
2. Objetivo
3. Mapeo del entorno
4. Estadisticas
5. Poblacion
6. Movimientos
7. Visualizacion

La navegacion lateral integra tambien los encabezados internos de cada pagina,
de modo que no aparezcan dos paneles separados para secciones y subsecciones.
